📖 REST API Documentation

The Go backend service exposes production-ready REST endpoints for out-of-Colombo cinema concessions.

1. Health Check

GET /api/v1/health
curl -i http://localhost:8080/api/v1/health

2. List Regional Out-of-Colombo Cinemas

GET /api/v1/cinemas
curl -i http://localhost:8080/api/v1/cinemas

3. Scrape Concession Menu

GET /api/v1/cinemas/{id}/concessions
curl -i http://localhost:8080/api/v1/cinemas/KND-KCC/concessions

4. Calculate Value-Optimized Recommendation

POST /api/v1/recommend
Content-Type: application/json

curl -X POST http://localhost:8080/api/v1/recommend \
  -H "Content-Type: application/json" \
  -d '{"cinema_id":"KND-KCC","budget_lkr":2500,"party_size":2,"redopay_tier":"Standard"}'

5. Evaluate User Cart & Redopay Discounts

POST /api/v1/cart/evaluate
Content-Type: application/json

curl -X POST http://localhost:8080/api/v1/cart/evaluate \
  -H "Content-Type: application/json" \
  -d '{"cinema_id":"KND-KCC","items":[{"item_id":"KND-01","quantity":1},{"item_id":"KND-03","quantity":2}]}'
